2026-11-18、[事前に固定した条件](luna-native-contract-v110s-protocol.md)で
GPT-6 Luna に12回送信した。native と JSON mode はともに6/6で値と引用が
正しく、他系列の実行先を答えた例も、他系列の記録を引用した例もなかった。
再試行・修復・検索は0回。

## 応答の内訳

各行は、系列名の差が5文字／末尾1文字の2条件と2方式を掛けた4応答。
各行の4件は、値だけでなく実際の引用IDと順序も一致した。

| 対象系列の終点 | 実際の回答 | 実際の引用ID | 厳密合格 |
|---|---|---|---:|
| 確定 | known, `P38f23` | `m020`, `m004`, `m009` | 4/4 |
| 終点の記録なし | unknown, null | `m020`, `m004` | 4/4 |
| 未確定と明記 | unknown, null | `m020`, `m018`, `m007` | 4/4 |

たとえば対象系列は `L739d9`、その実行先は `P38f23`（`m009`）。
近い条件には `L739db → Pb1803`（`m021`）もある。`m009` だけを
抜いて `m021` を残しても、両方式とも担当班と系列までの2件で引用を止めた。
別の対象依頼で未確定の記録を明示したときは、その記録も含めて3件を引用した。
引用IDは各対象依頼の中でのみ有効。

2つの新しい対象依頼、各条件1回の観測で、近い／遠いの差も方式差も出なかった。
[V1.9s](luna-native-contract-v19s-results.md) と結果の傾向は一致するが、
対象が異なり、横断的な効果量や一般的な誤り率は推定できない。次の候補は
終点を残したまま「担当班から系列への対応」だけを隠す条件。今回の12回には含まない。
