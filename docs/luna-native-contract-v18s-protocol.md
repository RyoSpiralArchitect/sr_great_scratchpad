# GPT-6 Luna Native Contract V1.8s: Standalone Heavy-Distractor Campaign

## Why A New Version

V1.6s showed citation discipline survives an18-distractor view, but the
relevant-to-noise ratio was still generous (3 relevant records among21
records). V1.8s triples the authored distractor count to54 per case —
the `distracted` view then supplies57 records — to find where the strict
citation gate bends, on the same best contract (semantic contract + flag
lexicon + flag scope) and the same standalone lineage discipline.

## Frozen Difference

Identical input semantics to V1.6s; `distractor_count: 54` is the only
spec change besides the seed. `make_state_case` accepts a distractor count,
so this is a parametric load step, not new case authoring: distractor text
shape, kinds, and targets are generated by the same frozen generator.
Non-distracted views are unchanged (distractors are filtered out), so
`source`/`empty`/`partial-*` views stay comparable in shape to V1.6s.
Views per scenario:25 total,50 calls,204,800 allocated output tokens.

Seed 26110321 is fresh; `standalone: true`, `parent: null`, no witnesses.
This remains a bounded authored-noise calibration, not retrieval efficacy.

## Budget And Gate

- Fifty new requests maximum:25 per arm,204,800 allocated output tokens.
- Explicit600,000 serialized input-byte ceiling (distracted views roughly
  triple in size) and4096 per-call output cap.
- Retries, repairs, schema smoke requests and retrieval/pilot calls:0.
- Same stop rules, same separate measurements, same25/25 future gate.
  No retrieval pilot or broad claim is authorized; standalone status bars
  lineage-relative claims.
